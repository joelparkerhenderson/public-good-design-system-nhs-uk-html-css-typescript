Skip Link Component - Basic Examples

This page demonstrates the Skip Link component in a realistic page layout. Skip links help keyboard-only users bypass repetitive navigation and jump directly to important page sections.

What are Skip Links?

Skip links are navigation aids that:

  • Improve accessibility: Help users with mobility impairments or those using screen readers
  • Save time: Allow users to bypass long navigation menus
  • Reduce frustration: Eliminate the need to tab through many elements
  • Follow standards: Required by WCAG 2.1 AA accessibility guidelines

Skip Link Behavior

The skip links on this page demonstrate several important behaviors:

Demo Target 1

This is a demonstration target that can receive focus when navigated to via a skip link. Notice how it becomes highlighted when focused.

Key Features:

  • Hidden by default: Skip links are positioned off-screen until focused
  • Visible when focused: Pressing Tab reveals them with high contrast styling
  • Smooth scrolling: Navigating to targets uses smooth scrolling (respects user preferences)
  • Target focusing: The destination element receives focus for continued navigation
  • Multiple links: Support for multiple skip destinations

Skip Link Targets

Skip links navigate to specific elements on the page. Here are the targets available on this page:

Main Content Target

The main content area (this section) is the primary skip link target. It has id="main-content" and tabindex="-1" to receive focus.

Navigation Target

The primary navigation menu is another common skip link target, allowing users to jump to navigation if needed.

Footer Target

The footer section provides additional navigation and information, useful for users who want to skip to the end of the page.

Implementation Examples

Here are different ways to implement skip links:

Single Skip Link

<a class="public-good-skip-link" href="#main">Skip to main content</a>

Multiple Skip Links

<div class="public-good-skip-links">
  <a class="public-good-skip-link" href="#main">Skip to main content</a>
  <a class="public-good-skip-link" href="#nav">Skip to navigation</a>
  <a class="public-good-skip-link" href="#footer">Skip to footer</a>
</div>

Target Element

<main id="main" tabindex="-1" role="main">
  <!-- Main content -->
</main>

Testing Your Skip Links

To ensure your skip links work properly:

  1. Keyboard Test: Press Tab on page load - skip links should be first
  2. Visibility Test: Skip links should be clearly visible when focused
  3. Navigation Test: Activating skip links should move focus to targets
  4. Screen Reader Test: Test with NVDA, JAWS, or VoiceOver
  5. Mobile Test: Ensure skip links work on mobile devices with external keyboards
Test this page: Try using Tab, Shift+Tab, Enter, and Space keys to navigate. Start from the top of the page and experience how skip links make navigation more efficient.
