Select - Helper Functions Example

The select component provides several helper functions for common use cases.

Simple select

Use createSimpleSelect() for basic dropdowns.

Required select

Use createRequiredSelect() for mandatory selections.

Multiple select

Use createMultiSelect() for multiple selections.

Dynamic options

You can add and remove options dynamically.

Enable/Disable

You can enable and disable selects programmatically.

JavaScript Code Examples

import { 
  createSimpleSelect, 
  createRequiredSelect, 
  createMultiSelect 
} from './select.js'

// Simple select
const simple = createSimpleSelect('transport', 'How do you travel?', [
  { value: 'car', text: 'Car' },
  { value: 'bus', text: 'Bus' }
])

// Required select
const required = createRequiredSelect('priority', 'Priority level', [
  { value: 'high', text: 'High' },
  { value: 'low', text: 'Low' }
])

// Multiple select
const multi = createMultiSelect('skills', 'Your skills', [
  { value: 'html', text: 'HTML' },
  { value: 'css', text: 'CSS' }
])
