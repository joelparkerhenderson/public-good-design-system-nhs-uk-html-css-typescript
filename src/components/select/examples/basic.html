Select - Basic Example

Use select to let users choose an option from a long list. Only use select as a last resort.

When to use select

  • when you have 4 or more options
  • when space is limited
  • when options are familiar to users

When not to use select

  • with less than 4 options - use radio buttons instead
  • when options are not familiar - users might not understand them
  • when you need users to compare options - use radio buttons
