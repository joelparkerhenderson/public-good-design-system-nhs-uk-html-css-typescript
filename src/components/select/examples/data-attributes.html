Select - Data Attributes Example

You can initialize select components using data attributes in your HTML. This is useful when you want to enhance existing HTML with JavaScript.

HTML Code

<div 
  data-public-good-select
  data-name="region"
  data-label="Which region do you live in?"
  data-hint="Choose the region that best describes your location"
  data-options='[
    {"value":"north","text":"North"},
    {"value":"south","text":"South"}
  ]'
></div>

Available data attributes

  • data-public-good-select - Required to initialize the component
  • data-name - The name attribute for the select element
  • data-label - The label text
  • data-hint - Optional hint text
  • data-error - Error message text
  • data-options - JSON array of option objects
  • data-required - Set to "true" for required select
  • data-disabled - Set to "true" for disabled select
  • data-multiple - Set to "true" for multiple selection
  • data-size - Number of visible options for multiple select
  • data-classes - Additional CSS classes
