Select - Multiple Selection Example

Use multiple select when users need to choose more than one option from a list. Only use this pattern when necessary - checkboxes are usually better.

Selected values:

    When to use multiple select

    • when users need to select multiple related options
    • when space is very limited
    • when all options are familiar to users

    When not to use multiple select

    • use checkboxes instead - they're easier to use
    • when users need to see all options at once
    • when options require explanation
