Pagination Component - Basic Examples

Examples demonstrating NHS UK Design System pagination component usage patterns.

Full Pagination (Previous and Next)

Most common pagination pattern with both previous and next page links. Used when navigating through a content series.

Understanding Diabetes

This is the main content of the current page. Users can navigate to related pages using the pagination below.

Pagination helps users understand they are part of a content series and provides context about adjacent pages.

Previous Only Pagination

Used on the last page of a content series where there is no next page available.

Getting Support - Final Page

This is the final page in the diabetes support guide series.

Only a previous page link is shown as this is the end of the content series.

Next Only Pagination

Used on the first page of a content series where there is no previous page available.

Diabetes Guide - Getting Started

Welcome to the comprehensive diabetes guide. This is the first page in the series.

Only a next page link is shown as this is the beginning of the content series.
