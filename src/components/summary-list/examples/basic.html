Summary List Component - Basic Examples

Summary lists let you summarise information, for example, a user's responses at the end of a form.

Basic Summary List

A basic summary list displays key-value pairs in a structured format using a description list.

HTML Structure

<dl class="public-good-summary-list">
  <div class="public-good-summary-list__row">
    <dt class="public-good-summary-list__key">Name</dt>
    <dd class="public-good-summary-list__value">Sarah Phillips</dd>
  </div>
  <div class="public-good-summary-list__row">
    <dt class="public-good-summary-list__key">Date of birth</dt>
    <dd class="public-good-summary-list__value">5 January 1978</dd>
  </div>
  <div class="public-good-summary-list__row">
    <dt class="public-good-summary-list__key">Contact information</dt>
    <dd class="public-good-summary-list__value">
      72 Guild Street<br>
      London<br>
      SE23 6FH
    </dd>
  </div>
</dl>

JavaScript

import { createSimpleSummaryList } from './summary-list'

const data = [
  { key: 'Name', value: 'Sarah Phillips' },
  { key: 'Date of birth', value: '5 January 1978' },
  { key: 'Contact information', value: '72 Guild Street\nLondon\nSE23 6FH' }
]

const summaryList = createSimpleSummaryList(data)
container.appendChild(summaryList.element)

Summary List with Actions

Summary lists can include action links, such as 'Change' or 'Edit', to allow users to modify the information.

HTML Structure

<dl class="public-good-summary-list">
  <div class="public-good-summary-list__row">
    <dt class="public-good-summary-list__key">Name</dt>
    <dd class="public-good-summary-list__value">Sarah Phillips</dd>
    <dd class="public-good-summary-list__actions">
      <ul class="public-good-summary-list__actions-list">
        <li class="public-good-summary-list__actions-list-item">
          <a class="public-good-link" href="/personal-details">
            Change<span class="public-good-visually-hidden"> name</span>
          </a>
        </li>
      </ul>
    </dd>
  </div>
</dl>

JavaScript

import { createEditableSummaryList } from './summary-list'

const data = [
  { key: 'Name', value: 'Sarah Phillips', editHref: '/personal-details' },
  { key: 'Date of birth', value: '5 January 1978', editHref: '/date-of-birth' },
  { key: 'Contact information', value: '72 Guild Street, London, SE23 6FH', editHref: '/contact-details' }
]

const summaryList = createEditableSummaryList(data)
container.appendChild(summaryList.element)

Summary List without Borders

You can remove the borders from a summary list by adding the --no-border modifier.

HTML Structure

<dl class="public-good-summary-list public-good-summary-list--no-border">
  <div class="public-good-summary-list__row">
    <dt class="public-good-summary-list__key">Name</dt>
    <dd class="public-good-summary-list__value">Sarah Phillips</dd>
  </div>
</dl>

JavaScript

import { createBorderlessSummaryList } from './summary-list'

const data = [
  { key: 'Name', value: 'Sarah Phillips' },
  { key: 'Date of birth', value: '5 January 1978' },
  { key: 'Contact information', value: '72 Guild Street, London, SE23 6FH' }
]

const summaryList = createBorderlessSummaryList(data)
container.appendChild(summaryList.element)

Multiple Actions per Row

You can include multiple action links for each row. Actions are separated by a border.

JavaScript

import { createSummaryList } from './summary-list'

const config = {
  rows: [
    {
      key: { text: 'Name' },
      value: { text: 'Sarah Phillips' },
      actions: {
        items: [
          { href: '/edit-name', text: 'Change', visuallyHiddenText: 'name' },
          { href: '/delete-name', text: 'Delete', visuallyHiddenText: 'name' }
        ]
      }
    }
  ]
}

const summaryList = createSummaryList(config)
container.appendChild(summaryList.element)

Data Attribute Initialization

Summary lists can be initialized from HTML data attributes for CMS or server-rendered content.

HTML

<div 
  data-public-good-summary-list
  data-id="data-attr-summary"
  data-rows='[
    {
      "key": {"text": "Name"}, 
      "value": {"text": "Sarah Phillips"},
      "actions": {"items": [{"href": "/edit-name", "text": "Change", "visuallyHiddenText": "name"}]}
    }
  ]'
></div>
