Inset Text Component - Basic Examples

This page demonstrates the basic usage of the Inset Text component for highlighting important content that users need to understand, even if they don't read the whole page.

NHS UK Design System Guidelines

Use inset text to: Help users identify and understand important content on a page

When to use: On content pages where specific information needs to stand out

When NOT to use: On transactional pages, for time-critical health information (use warning callout instead), or to tell users to contact GP

A simple inset text with plain text content and the default screen reader label.
Information:

You can report any suspected side effect to the UK safety scheme.

Inset Text with Rich Content

Inset text containing formatted text, links, and lists for more complex information.
Information:

Before your appointment, make sure you have:

  • Your NHS number (found on any NHS letter)
  • A list of any medicines you're currently taking
  • Details of any allergies or reactions to medicines
  • Your health records if you have them

If you don't have your NHS number, you can find it here.

<div class="public-good-inset-text"> <span class="public-good-sr-only">Information: </span> <div class="public-good-inset-text__content"> <p>Before your appointment, make sure you have:</p> <ul> <li>Your <strong>NHS number</strong> (found on any NHS letter)</li> <li>A list of any medicines you're currently taking</li> <li>Details of any <em>allergies or reactions</em> to medicines</li> <li>Your <a href="/health-records">health records</a> if you have them</li> </ul> <p>If you don't have your NHS number, <a href="/find-nhs-number">you can find it here</a>.</p> </div> </div>

Data Attribute Initialization

Inset text components can be initialized from data attributes for easier integration.

This inset text was created from data attributes.

<div data-public-good-inset-text data-text="This inset text was created from data attributes." data-hidden-label="Data attribute information: " data-classes="public-good-inset-text--success"> </div>

Accessibility Features

All inset text components include comprehensive accessibility support.
Accessibility information:

This inset text demonstrates key accessibility features including hidden labels for screen readers, proper semantic structure, and keyboard navigation support for interactive elements.

Accessibility Features:

  • Screen reader support: Hidden labels provide context
  • Semantic HTML: Uses proper div structure for content organization
  • Keyboard navigation: All interactive elements are keyboard accessible
  • Focus indicators: Clear focus outlines for keyboard users
  • High contrast support: Adapts to high contrast mode preferences
  • Print support: Optimized styling for printing
✓ Do
  • Use inset text to highlight important information
  • Keep the content concise and focused
  • Include proper hidden labels for screen readers
  • Use appropriate variants (health, warning) for different types of content
  • Test with screen readers and keyboard navigation
✗ Don't
  • Overuse inset text - it loses impact
  • Use for time-critical or urgent health information
  • Use on transactional pages
  • Forget the hidden label for accessibility
  • Use for decorative purposes only
