Review Date Component - Basic Example

This example demonstrates the basic Review Date component showing page currency information.

Standard Review Date

This is the most common pattern used on NHS.UK pages:

Page last reviewed: 15 March 2023
Next review due: 15 March 2026

View code 
<p class="public-good-review-date public-good-body-s public-good-u-secondary-text-color public-good-u-margin-top-7 public-good-u-margin-bottom-0">
  Page last reviewed: 15 March 2023<br>
  Next review due: 15 March 2026
</p>

JavaScript Implementation

Create review dates programmatically:

View JavaScript 
import { createSimpleReviewDate } from './review-date'

const reviewDate = createSimpleReviewDate('2023-06-15', '2026-06-15')
document.getElementById('js-review-date-1').appendChild(reviewDate.element)

Last Reviewed Only

Sometimes you only need to show when content was last updated:

View JavaScript 
import { createLastReviewedOnly } from './review-date'

const reviewDate = createLastReviewedOnly('2023-09-20')
document.getElementById('js-review-date-2').appendChild(reviewDate.element)

Data Attribute Initialization

Initialize review dates from HTML data attributes:

View HTML 
<div 
  data-public-good-review-date
  data-last-reviewed="2023-12-01"
  data-next-review="2026-12-01"
  data-classes="public-good-body-s public-good-u-secondary-text-color public-good-u-margin-top-7"
></div>
