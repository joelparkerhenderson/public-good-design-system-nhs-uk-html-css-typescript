Image Component - Basic Examples

This page demonstrates the basic usage of the Image component with various configurations and accessibility features.

Basic Image

A simple image with alt text for accessibility.
<figure class="public-good-image"> <img class="public-good-image__img" src="/path/to/image.jpg" alt="Descriptive alt text"> </figure>

Image with Caption

An image with a descriptive caption using the figcaption element.
<figure class="public-good-image"> <img class="public-good-image__img" src="/path/to/image.jpg" alt="Health information visual"> <figcaption class="public-good-image__caption"> This image shows important health information. </figcaption> </figure>

Responsive Image

An image that adapts to different screen sizes using srcset and sizes attributes.
<figure class="public-good-image"> <img class="public-good-image__img" src="/path/to/image-800w.jpg" srcset="/path/to/image-400w.jpg 400w, /path/to/image-800w.jpg 800w, /path/to/image-1200w.jpg 1200w" sizes="(max-width: 768px) 100vw, 50vw" alt="Responsive image description"> <figcaption class="public-good-image__caption"> Caption explaining the responsive image. </figcaption> </figure>

Lazy Loaded Image

An image that loads only when it comes into the viewport, improving page performance.
<figure class="public-good-image"> <img class="public-good-image__img" src="/path/to/image.jpg" loading="lazy" alt="Lazy loaded image description"> <figcaption class="public-good-image__caption"> This image loads when it comes into view. </figcaption> </figure>

Data Attribute Initialization

Images can be initialized from data attributes in HTML for easier integration.
Data Attribute Image
<div data-public-good-image data-src="/path/to/image.jpg" data-alt="Image description" data-caption="Image caption text" data-loading="lazy" data-classes="public-good-image--bordered"> </div>

Accessibility Features

All images include comprehensive accessibility support following WCAG 2.1 AA guidelines.

Accessibility Features:

  • Alt text: Descriptive alternative text for screen readers
  • Semantic HTML: Uses figure and figcaption elements
  • Focus indicators: Visible focus outlines for keyboard users
  • High contrast support: Adapts to high contrast mode
  • Reduced motion: Respects prefers-reduced-motion settings
  • Print support: Optimized for printing
